UK Road Accident Analysis Dashboard (2024–2025)

Project Overview

This project analyzes road accident data from the United Kingdom for the years 2024 and 2025. The dataset was analyzed using Microsoft Excel, where Pivot Tables, KPIs and dashboard visualizations were created to uncover key patterns in road accident casualties.
The goal of this analysis was to transform raw accident data into meaningful insights that can help understand factors contributing to road incidents.

Objectives

Analyze road accident casualty trends.
Identify which vehicle types contribute most to accidents.
Examine how road type, road surface and light conditions affect accident frequency.
Compare urban vs rural accident distribution.
Build a simple interactive Excel dashboard for data exploration.

Dataset Information

The dataset contains 417,883 total casualties recorded across different categories including:
-Vehicle Type
-Road Type
-Road Surface Condition
-Light Condition
-Urban/Rural Area

Key Takeaway
Most road accidents occurred during normal driving conditions (dry roads, daylight, urban areas), suggesting that traffic volume and driver behavior are major contributors rather than extreme weather conditions.
